# Personal Expense Tracker

A personal expense tracking web application built with Python, FastAPI, SQLite, HTML, CSS, and JavaScript.

## Features

- User registration and login
- Secure, user-specific expense management
- Add, edit, and delete expenses
- Track today's expenses
- Monthly expense analysis
- Category-wise spending visualization
- Data persistence using SQLite
- Responsive user interface

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, FastAPI
- **Database:** SQLite
- **Visualization:** Chart.js
- **Version Control:** Git and GitHub

## Run Locally

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies.
4. Configure the `EXPENSES_SECRET_KEY` environment variable.
5. Start the FastAPI backend.
6. Serve the frontend locally.

See the project configuration and source files for the exact commands and dependencies.

## Security

- Keep secret keys and credentials private.
- Do not upload database files containing personal information.
- Use a secure deployment configuration before exposing the application publicly.
